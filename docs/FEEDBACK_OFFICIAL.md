# 官方反馈材料：第三方代管小程序的授权与域名配置缺口

> 用途：把「正式版发布被域名白名单卡住」这件事，作为**产品机制问题**正式反馈给
> WorkBuddy 官方（主）与微信公众平台 / 腾讯客服（辅），推动改进，而不是当作个人求助。
> 本文所有代码块均可整段复制，直接粘贴到意见反馈框或邮件正文。

---

## 一、问题定性（先看这段，决定了反馈的力度）

这不是「用户不会配域名」，而是**第三方代管模式下一项必要能力缺失**：

- WorkBuddy 主打「一句话生成 + 一键发布小程序」，这个体验很好，用户正是冲着它来的。
- 但小程序一旦走第三方平台代管，**request 合法域名只能由第三方平台侧配置**，用户自己在公众平台后台看不到、也改不了。
- WorkBuddy 当前的发布面板（绑定 / 发布 / 更新 / 解绑 / 小程序设置）里**没有域名配置入口**，官方文档也没有任何相关说明。
- 结果：**体验版正常、正式版全部行情被拦**（`request:fail url not in domain list`），用户卡在最后一步无法上线。
- 用户被迫二选一：① 等官方人工代加域名；② 自己去下载微信开发者工具、解除第三方平台授权、再手工配置域名——等于退回到「不用 WorkBuddy 也能发」的老路，与一站式发布的初衷相悖。

**一句话诉求**：请 WorkBuddy 补齐第三方代管模式下的「request 合法域名自助配置」能力；在此之前，请先人工代加本期域名，解除正式版发布阻塞。

## 三、渠道 B（辅）：咨询 / 反馈给微信公众平台

说明：按微信的既定设计，第三方代管模式下服务器域名由第三方平台配置，所以腾讯客服
大概率会让你「联系第三方平台」。发给它的价值在于：① 留下正式记录；② 确认是否存在
「用户自助申请变更域名」的官方通道，作为向 WorkBuddy 施压的依据。

发送路径：微信里搜索「腾讯客服」小程序 → 选择「微信公众平台 / 小程序」类目发起咨询；
或在 mp.weixin.qq.com 后台右下角「客服」入口提交。

## 四、提交后该做什么

1. 渠道 A、B 都提交一遍，A 为主、B 留记录；
2. A 提交时务必**附截图 + 勾日志**，能显著提高定位与响应速度；
3. 保留反馈/工单编号，若 2–3 个工作日无回复，用原渠道补充追问；
4. 官方代加域名后，回到 WorkBuddy 分享面板点「更新」，**重新提交正式版发布**才会生效。

## 五、如果官方迟迟不处理：备选路线（你自己掌控）

- 按 `DOMAIN_WHITELIST.md` 第五节解除第三方授权，自己在公众平台配置 9 个域名；
- 代价：后续发版需使用微信开发者工具手工上传提审，WorkBuddy 不再代发；
- 建议把这作为「倒逼官方改进」的备选，而非首选——先走反馈渠道，给官方一次机会。
