# 打赏功能说明

首页最底部有一个「打赏支持」模块：快捷金额 2 / 4 / 6 / 8 元 + 自定义输入，确认后弹出微信收款码，用户扫码支付。

## 收款方式

采用**微信个人收款码**（无需企业主体、无需商户号、无需后端签名）。

## 如何换成你自己的收款码（重要）

当前 `images/reward-qr.png` 是一张**占位示意图，不能扫码**。上线前请按下面步骤替换：

1. 打开微信 →「我」→「服务」→「收付款」→「二维码收款」→ 保存收款码图片到手机/电脑。
2. 把保存的收款码图片命名为 `reward-qr.png`，覆盖掉 `images/reward-qr.png` 这个文件。
3. 重新用开发者工具预览/上传即可。

代码无需任何改动——小程序读取的就是这一个文件路径（在 `pages/index/index.js` 顶部的 `REWARD_QR_SRC` 常量）。如果以后想把图片放到别处或改用网络图片，只改这个常量即可。

## 交互逻辑

- 选择快捷金额会清空自定义输入，展示金额同步更新。
- 自定义输入只允许数字，最多两位小数，上限 9999 元。
- 金额无效（空或 0）时点「确认打赏」会提示先输入有效金额。
- 弹窗内可长按二维码识别，或点「保存收款码」存到相册（需相册权限）。
- 该模块与其他首页模块一样支持折叠/展开，状态会本地保存。

## 说明

个人收款码是静态码，小程序无法自动确认用户是否完成支付、也无法校验支付金额是否等于所选金额——金额选择仅作为提示展示给用户。这是个人收款码方案本身的限制，如需自动核销金额，必须升级为微信支付商户号（企业/个体工商户主体）。
