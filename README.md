# 算力看盘

> 一个把「看盘」从**看行情**升级为**算概率 + 给纪律**的微信小程序。

大多数看盘工具做的是同一件事：把价格、涨跌幅、资金流画给你看，然后让你自己判断。
算力看盘做的不是这件事——它把判断本身**建成了可解释的模型**：市场现在处于什么状态、底部到了几成、明天该进攻还是空仓，都由数据算出来，并且每一步都能点开看依据。

## 它到底不一样在哪

| 普通看盘软件 | 算力看盘 |
| --- | --- |
| 给你一堆指标，结论自己下 | 直接给出**状态机结论**：枯竭 / 脉冲 / 持续 / 出逃 / 居中 |
| 涨了就说好、跌了就说空 | **六条门禁**按苛刻条件打分，不满 6 条明确告诉你「禁止买」 |
| 「估值低了可以抄底」这种口号 | 把底部拆成**估值 / 资金 / 叙事三层底**加权算出概率，低估值只占 20% |
| 预测出错就删掉重来 | 每次预测自动进**复盘账本**，次日回填真实涨跌，命中率长期可查 |
| 数据全靠实时，断了就白屏 | 行情**三级降级**、复盘数据**本地 + 磁盘 + 云端三层保险**，重装不丢 |

一句话：**它不是行情显示器，是一套带纪律约束的决策辅助系统。** 模型是启发式打分，不是预测承诺；界面会诚实标注数据缺口和快照口径。

## 核心模型

### 一、多空博弈（A股 · ASFMM-A 脉冲市状态机）

这是首页的重头戏。设计前提是一个反直觉的判断：**市场是「脉冲市」不是「连续市」**——量能是跳变（地量→天量→地量），不是渐变。所以传统 EMA 平滑分数被降级为参考，主判据换成三步走：

1. **量能状态机（现在是什么状态）**：五态判定——
   - `STARVE 枯竭`：成交 < 20日均量 × 0.7，流动性休眠
   - `PULSE 脉冲`：单日放量 ≥ 1.25× 且 > 均量 × 1.1，一日游嫌疑，只看不买
   - `SUSTAIN 持续`：连续 ≥ 3 日站稳均量且不衰减，**唯一允许看多的状态**
   - `DUMP 出逃`：放量下跌 > 1%，派发，不接飞刀
   - `NEUTRAL 居中`：无方向
2. **T+1 / T+2 硬确认（上次脉冲是真是假）**：对最近一次脉冲做事后验证。T+1 三关（不破脉冲日低点 / 量能 ≥ 60% / 跌幅 ≤ 1.5%），T+2 两关（重心上移 / 不破 T+1 低点）。结论分「双确认通过（真底）」「两日游后衰竭」「一日游确认（诱多）」。最近 3 日内的脉冲若被判诱多，**一票否决**，门禁全亮也不给买点。
3. **六条门禁（现在能不能买）**：地量衰竭、不破前低、情绪收敛（炸板率 ≤ 30% 且涨停 ≥ 30 家）、探底形态（长下影/十字星）、资金承接（大单净流入）、无政策雷。6/6 才允许 1/3 仓试错、止损设前低下方 1%；5 条观察，≤ 4 条禁止买。

连续模型的综合动量 `M`（0–100）和六个维度（P 仓位空间 / R 流入强度 / BIG 大资金 / A 加速度 / E 情绪温度 / G 卖压再生）全部降级为温度计和象限参考；关键字段缺失超过 2 项时会亮起质量闸门，明确提示「M 不可用于方向判断」。

> 代码：`utils/bgame.js`（v3 状态机 + v2 因子）、`utils/verify.js`；算法原型 `automation/asfmm_a_model_v2.py`。完整逐行释义见 `docs/AGAME_GUIDE.md`。

### 二、港股底部研判（三层底概率模型）

这是首页第二个核心模型，解决的问题是：**「便宜」不等于「到底」**。它把底部拆成三层，用加权到达度算出一个概率：

| 层 | 权重 | 判定依据 |
| --- | --- | --- |
| 估值底 | 20% | PE 历史分位：< 10% 已到、< 20% 磨底，否则未到 |
| 资金底 | 30% | 南向连续净流入天数 + 近 N 日净流入占比 + 主动低配程度 |
| 叙事底 | 50% | 资本开支环比方向 + 经营/投资现金流净额 + 利润增速 |

权重刻意让估值只占 20%——**核心矛盾（盈利与资本开支）没拐头，估值便宜不构成买入理由**。概率分档：≥ 70%「底部大概率已现」、≥ 45%「接近底部区域」、≥ 30%「左侧磨底」、< 30%「底部未到」，每档配明确操作纪律。

它最特别的地方是**数据驱动、不写死**：结论不存文本，全部由输入算出来；换季度只要财报更新，叙事底自动重算。数据分两类且界面严格区分：

- **实时项**（每次进页面拉取）：恒科报价与日K、南向净买入历史、腾讯季度财报——恒科点位、南向连续流入天数与月度/YTD 累计、营收与现金流增速都随数据实时变化。
- **快照项**（无免费接口）：估值分位、外资持仓、资本开支单季值、ETF 折价、美债。这些锁定在各自报告期，界面标注「研报快照」和基准日；定时任务在换季/换月/换年/新季报发布时自动推进报告期标签，**不会出现「旧值套新标签」**。

> 代码：`utils/hkbottom.js`（计算引擎）、`utils/market.js`（数据抓取）；刷新脚本 `automation/hkbottom_refresh.py`，云端表 `hk_bottom_input`，每工作日 16:45 自动维护。

### 三、次日倾向（半导体 / AI 算力）

两个跨市场打分卡，都是**可解释的加权因子**，把分数拆开逐条展示：

- **AI 算力次日倾向**：韩股 0.32（SK海力士、三星）+ 美股半导体 0.28（SOX、英伟达）+ 股指期货相对现货强弱 0.22 + 动量 0.18。逻辑基础是韩股与美股半导体先于 A 股反应。
- **港股次日倾向**：恒科指数（权重最高）+ 龙头加权（腾讯/阿里/美团/小米）+ 涨跌家数（板块宽度）+ 半导体链（中芯、华虹）。港股 16:00 收盘早于 A 股，夜盘期货可二次验证。

### 四、其余分析模块

- **明日实操验证**：把模型底牌和盘面实时数据对照，三个检查点——早盘承接、量能回升、破位止损，验证「洗盘成立 / 偏涨兑现 / 执行防守」哪条路径在走。
- **全球市场**：恒科指数及期货、首尔综合、日经225及期货、标普500、纳指期货、VIX、黄金白银、离岸人民币，三路数据源互不干扰。
- **板块热力图与资金流**：行业/概念涨跌榜、板块成分股（涨幅/跌幅前 30）、机构/主力/大户/散户四类资金净流，并可从板块一路点到个股详情。
- **标的详情**：分时、日K、周K、月K，双指缩放；日K/周K/月K 东财→腾讯→缓存三级降级，覆盖 A股/港股/美股/韩股。

## 数据与技术架构

**行情三级降级**：东方财富 push2 → 腾讯行情 → 本地缓存。任何一路限流或被拦，自动切下一路；桌面微信离线时用全市场快照兜底。所有对外域名集中在 request 合法域名白名单（东财 push2 / push2his / datacenter-web / searchapi、腾讯 qt.gtimg.cn / web.ifzq.gtimg.cn、新浪 hq.sinajs.cn）。

**三层数据保险（vault）**：`localStorage → USER_DATA_PATH 磁盘文件 → 云端备份`。复盘历史、次日倾向记录、净空单历史、配置、自选、持仓这些本机算出来的数据，在重新发版、清缓存、切开发版后依然能恢复；并提供导出/导入文本供换机搬运。

**云端定时任务（写表 → 小程序只读）**：A股资金面（两融/大单/ETF/北向，每交易日 16:30）、模型预测复盘、政策输入、港股底部研判低频输入（每工作日 16:45）由自动化脚本抓取写入云数据库，小程序端免发版读取。跨次状态存云数据库，不依赖本机文件。

**技术栈**：微信小程序原生（WXML / WXSS / JS）、Canvas 2D 图表、WorkBuddy Cloud SDK。图表与模型均为前端实现，云侧负责低频数据与持久化。

```
  signal.js      次日倾向（半导体）
  hktech.js      港股次日倾向
  verify.js      明日实操验证
  market.js      行情抓取与三级降级
  vault.js       三层数据保险
  cloudData.js   云端表读写

```
